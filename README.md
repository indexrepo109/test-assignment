# Frontend Developer Test — No Setup Required

## Time limit

Please spend approximately **5–10 minutes**.

## What to do

Complete the two TODO items in `js/app.js` and `styles.css`. Most of the dashboard is already implemented.

 You may double-click `index.html` to check the result in a browser, but this is optional.

## Your two tasks

1. Finish `getVisibleTransactions()` so search and status filtering work together. Search must be case-insensitive and match the customer name or transaction ID.
2. Add clear colors for `.status--completed`, `.status--pending`, and `.status--failed` in `styles.css`.

## Submission

Return the complete folder with your edited files. Add short comments at the bottom of `js/app.js` explaining:

- One technical decision you made.
- One improvement you would make with more time.
- Whether you used an AI tool and, if so, how.

We evaluate correctness, readable JavaScript, basic CSS judgment, edge cases, and your ability to explain the code.
